# 数独 Sudoku

一个基于 Web 的数独（Sudoku）谜题游戏，原生 SVG 渲染，内置逻辑解题器。
支持 4×4 / 6×6 / 9×9 / 12×12 / 16×16 等标准尺寸与任意 4..25 方形题面、自定义题板、图片导入。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5195/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 在 N×N 格中填入 1..N（9×9 用 1..9，16×16 用 1..9 与 A..G），每行、每列数字不重复
- 每个宫（标准数独是 3×3；16×16 是 4×4）内数字也不能重复
- 题面预填数字不能修改

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 选中该格并高亮（只选中，不填数、不循环、拖动不涂写） |
| 数字面板 | 棋盘左侧；先选格，再点数字写入选中格；「清除」清空选中格（未选格时只提示先选格） |
| 数字键 1–9 | 给选中格填 1–9（16×16 时 Shift+A…G 填 10–16）；输入后保持选中、不自动跳格 |
| 0 / Backspace / Delete | 清除选中格（没有选中格时 `0` 为视图复位） |
| 方向键 | 移动选中格 |
| 右键点格 | 只选中该格（不再写入/清除） |
| 滚轮 / 中键 / 空白拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道 9×9 题，题目均校验唯一解；图片导入的大尺寸题放在独立文件里，不会被重新生成覆盖
- **多尺寸支持**：内置 4/6/9/12/16，自定义 4..25，渲染/命中/校验/求解/逻辑回放全部按实际宽高工作
- **自定义题板**：9×9 或 16×16 数字录入（鼠标点击循环、键盘 1–9 与 A–G、方向键），保存到题库后可编辑、两步确认删除
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由（基础规则 / 高级定式 / 反证 / 回溯分别标注）；回放中按钮变为停止，按 `P` 暂停/继续
- **从当前盘面继续**：逻辑解题以当前盘面快照为起点（预填 + 玩家已填都作为已知），回放帧只追加新推演、`from` 取该格当前值，不会把玩家已填的数字改回空
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：每次面板/键盘输入记一步，可逐步撤销 / 重做
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或从空白处拖拽平移

## 逻辑定式

逻辑解题器按「候选集」推理，回放里每帧标注所用定式（规则 1–5）：

| 规则 | 定式 | 说明 |
|------|------|------|
| 1 | 唯一候选 | 行/列/宫内已用数字排除后只剩一个候选 |
| 2 | 单元隐性唯一 | 某数字在行/列/宫内只剩一个位置 |
| 3 | 高级集合定式 | 宫-行/列交叉（pointing / claiming）、显性/隐性数对与三数组、X-Wing、Swordfish、Skyscraper、XY-Wing、XYZ-Wing、唯一矩形 |
| 4 | 反证 | 逐个试填，若立刻矛盾则该数字成立（带完整传播的兜底推理） |
| 5 | 回溯试探 | 规则 1–4 都不够时用回溯补完 |

- 唯一矩形依赖「题面唯一解」这一前提，只在确认唯一解后启用（9×9 及以下自动校验，大棋盘默认关闭）。
- 规则 1–3 全部是「候选消除 / 落子」，每一步都能由集合条件证明，不针对具体题目硬编码。
- 反证与回溯保留为兜底：规则 4 会先做单格试填验证，规则 5 只在逻辑完全推不动时补完。
- `npm run audit` 会统计每题的基础 / 高级定式 / 反证 / 回溯帧数，可直接对比定式效果。

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 项目结构

```
src/
  main.ts
  core/
    app.ts / ui.ts / view.ts      界面、交互、缩放、回放控制
    store.ts / library.ts         题库、进度、上次题目存储
    audio.ts / fx.ts              音效与落子特效
  game/
    adapter.ts                    游戏规则接入
    rules.ts                      规则引擎：基础传播 + 高级定式（任意 N / 任意宫形）
    logic.ts                      逻辑解题回放
    render.ts / state.ts          SVG 渲染与盘面状态
    validate.ts / solver.ts       实时校验与回溯求解
    puzzles.ts                    题库加载与解码（任意 N）
    puzzles-data.ts               npm run gen 生成的内置题（会被覆盖）
    imported-puzzles.ts           图片导入题（不影响内置题，不被 gen 覆盖）
```

## 尺寸支持矩阵

| 尺寸 | 宫划分 | 内置题 | 自定义题板 | 图片导入 | 求解/校验/逻辑回放 |
|------|--------|--------|-----------|----------|------------------|
| 4×4 | 2×2 宫（4 宫） | ✅ 2 题 | ✅ | ✅（4..25 通用） | ✅ |
| 6×6 | 2×3 宫（6 宫） | ✅ 2 题 | ✅ | ✅ | ✅ |
| 8×8 | 2×4 宫（8 宫） | —（可自定义/导入） | ✅ | ✅ | ✅ |
| 9×9 | 3×3 宫（9 宫） | ✅ 6 题（旧题库原样保留） | ✅ | ✅ | ✅ |
| 10×10 | 2×5 宫 | — | ✅ | ✅ | ✅ |
| 12×12 | 3×4 宫（12 宫） | ✅ 2 题 | ✅ | ✅ | ✅ |
| 14×14 | 2×7 宫 | — | ✅ | ✅（识图实测） | ✅ |
| 15×15 | 3×5 宫 | — | ✅ | ✅ | ✅ |
| 16×16 | 4×4 宫（16 宫） | ✅ 2 题 | ✅ | ✅（识图实测） | ✅ |
| 18..25 方形 | 标准矩形宫（如 5×5） | — | ✅ | ✅ | ✅（超大棋盘受求解预算限制） |
| 质数边长 5/7/11/13/17/19/23 | 无矩形宫，退化为拉丁方（宫=整行） | — | ✅ | ✅ | ✅ |

- 数值显示：1–9 显示为数字，10–25 显示为 A–P（`board` 编码用 36 进制，一格一个字符）。
- 编码兼容：`board = givens|regions`，每格 1 个 36 进制字符。旧 9×9 题库里的 `'0'..'9'` 与新编码完全一致，
  无需迁移；存档（`cells` 串）同理，旧进度可直接续玩。
- 内置题库：旧 9×9 六题（`puzzles-data.ts`）保持字节级不变；多尺寸题在 `puzzles-extra-data.ts`，
  `npm run gen` 会同时校验生成（旧 9×9 可原样复现）。
- 限制：只支持正方形题面；自定义/导入边长 4..25；36×36 编码上界未开放（性能与可玩性考虑）。

## 从图片导入题库

```bash
npm run import-image -- month.png --verify                    # 预览识别结果并校验唯一解
npm run import-image -- month.png --append                     # 追加到识图题库（需唯一解）
npm run import-image -- puzzle.png --size 16 --append          # 指定网格尺寸
npm run import-image -- puzzle.png --json out.json             # 只导出 JSON，不写题库
npm run import-image -- puzzle.png --map "3,4=G,5,1=7"         # 人工覆盖误识别的格子
```

说明：

- Playwright + Edge 自动识别网格线、数字/字母字形（支持 9×9 / 16×16 等）；字符集自动判定（如 `123456789ABCDEFG`）。
- `--map` 人工覆盖格子，坐标 0 基，格式 `x,y=字符`（列,行），可修正个别误识别。
- `--verify` 调项目 solver（支持任意 N）校验唯一解并生成参考解；`--append` 把题面写入
  `src/game/imported-puzzles.ts`，重启/刷新后即出现在左侧题库并可游玩。
- 写入时用 36 进制编码，所以 16×16 的 10–16（A–G）与 16 个宫都能存；9×9 旧格式保持不变。
- `npm run gen` 只重写 `src/game/puzzles-data.ts`（内置题），不会覆盖 `imported-puzzles.ts`。
- 识别依赖图片字体与模板库近似度，个别格可能需要 `--map` 修正后重跑。

## 命令

```bash
npm run dev       # 开发服务
npm start         # 开发服务 + 自动打开浏览器
npm run build     # tsc --noEmit + vite build
npm run gen       # 重新生成多尺寸题库（旧 9×9 保持稳定）
npm run check     # 审计题库（内置 + 识图导入，任意 N）
npm run verify    # 参考解、逻辑回放与交互验证
npm run audit     # 逐题审计逻辑解题（基础/高级定式/反证/回溯帧 + 推满率）
```
